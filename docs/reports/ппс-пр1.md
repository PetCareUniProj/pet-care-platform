# **1\. Назва проекту** {#1.-назва-проекту}

Створення клієнт-серверної платформи “Pet Connect” для надання цифрових послуг у сфері догляду за домашніми тваринами.

# **2\. Предметна область** {#2.-предметна-область}

Проект “Pet Connect” знаходиться на перетині кількох сучасних та динамічно зростаючих предметних областей, що визначає його комплексність та актуальність. Це гібридна система, що поєднує класичний догляд за тваринами з передовими цифровими технологіями.

## **2.1. Ветеринарна медицина та догляд за домашніми тваринами (Pet Care)** {#2.1.-ветеринарна-медицина-та-догляд-за-домашніми-тваринами-(pet-care)}

Система безпосередньо стосується здоров'я та добробуту тварин, інтегруючи уявну ветеринарну CRM систему (для прикладу функціонування застосунку). Предметна область тут охоплює:

* Проактивний догляд: Система зміщує фокус з реактивного лікування (коли проблема вже виникла) на проактивну профілактику. Мобільний застосунок "Pet Connect" виступає як цифровий помічник, що заздалегідь нагадує про планові процедури — від щеплень до сезонних обробок від паразитів.  
* Підтримка лікування: Контроль за прийомом ліків, що особливо важливо при тривалій терапії.

## **2.2. Інформаційні технології та розробка програмного забезпечення** {#2.2.-інформаційні-технології-та-розробка-програмного-забезпечення}

Це технічна основа, що дозволяє реалізувати функціонал проекту. Ця область включає:

* Розробка мобільних застосунків: Створення кросплатформенного мобільного застосунку "Pet Connect", який є основною точкою взаємодії для кінцевого користувача. Ключовими аспектами є інтуїтивний UI/UX, інтеграція з системними функціями (календар, сповіщення) та надійна робота в офлайн-режимі.  
* Веб-розробка: Реалізація окремого веб\-сайту, що функціонує як інтернет-магазин. Він має бути адаптивним, безпечним для проведення онлайн-платежів та зручним для управління товарами.  
* Проектування API (Application Programming Interface): Розробка RESTful API, що слугує "мостом" між мобільним застосунком та інтернет-магазином. Саме API дозволяє реалізувати безшовну інтеграцію, наприклад, можливість замовити товар прямо з екрана нагадування в "Pet Connect".

## **2.3. Електронна комерція**  {#2.3.-електронна-комерція}

Проект включає повноцінний e-commerce компонент, орієнтований на нішевий ринок — ветеринарні товари. Це не просто онлайн-вітрина, а інтелектуальна комерція:

* Модель передплати (Subscription Model): Надає користувачам можливість автоматизувати регулярні покупки (корм, ліки від алергії), що підвищує зручність та забезпечує стабільний дохід для бізнесу.

Таким чином, предметна область проекту "Pet Connect" є комплексним поєднанням ветеринарного догляду, розробки програмного забезпечення та електронної комерції, спрямованим на створення єдиної, зручної та корисної екосистеми для сучасного власника домашньої тварини.

# **3\. Тип проекту** {#3.-тип-проекту}

Проект можна охарактеризувати за кількома критеріями:

* *За галуззю застосування*: IT-проект, оскільки його кінцевим результатом є створення та впровадження програмного продукту.  
* *За основною метою*: Комерційний проект, спрямований на створення рішення, що має потенціал для монетизації та підвищення конкурентоспроможності бізнесу (ветеринарної клініки).  
* *За ступенем інноваційності*: Інноваційний проект, оскільки він пропонує нові підходи до взаємодії клієнта з сервісом, включаючи модель передплати та застосування елементів AI для розшифровки рецептів.

Для більш глибокої та академічно обґрунтованої класифікації, звернемося до типізації, наведеної у методичних рекомендаціях \[1, с. 24\]. Згідно з нею, проект "Pet Connect" найбільш повно відповідає категорії:  
*Проекти типу 4: Розробка програмного забезпечення (Software Development)*.  
Це обґрунтовується наступними характеристиками проекту, що збігаються з описом даного типу:

1. Масштаб проекту: Проект є відносно невеликим за обсягом робіт та складом команди, що відповідає характеристиці "...як правило, менші".  
2. Міжнародний потенціал: Програмний продукт, особливо мобільний застосунок, за своєю природою не має географічних кордонів. Він може бути легко поширений через глобальні платформи, такі як App Store та Google Play, що відповідає ознаці "...мають значно більший міжнародний компонент".  
3. Кількість залучених дисциплін: Хоча проект включає кілька напрямів (backend, frontend, mobile development, UI/UX design), всі вони належать до єдиної галузі — розробки програмного забезпечення. Це відповідає тезі "...кількість дисциплін, що беруть участь у проекті, як правило, низька", особливо у порівнянні з проектами типу E\&C (Проектування та будівництво), де залучені інженери-будівельники, архітектори, геологи, електрики тощо.

# **4\. Тривалість проекту** {#4.-тривалість-проекту}

Загальна тривалість проекту становить **12 тижнів: з 8 вересня 2025 року до 1 грудня 2025 року.**  
Проект буде реалізовано за ітеративним підходом, що передбачає паралельні потоки робіт з аналізу, проектування та розробки. Це дозволить розпочати створення програмного продукту на ранніх етапах та гнучко адаптувати його відповідно до уточнених вимог.  
**Етап 1: Ініціація та базове планування (8 вересня — 22 вересня 2025 р.)**

* Цілі: Сформувати команду, визначити тему та загальну візію проекту. Створити початковий план робіт.  
* Результат: Детальний план проекту (Практична робота №1).

**Етап 2: Аналіз вимог та розробка архітектурного фундаменту (23 вересня — 13 жовтня 2025 р.)**  
На цьому етапі робота ведеться паралельно: аналітики формалізують вимоги, а розробники вже закладають технічну основу.

* Цілі з розробки:  
  * Налаштування середовища розробки та системи контролю версій (Git).  
  * Проектування архітектури бази даних (схеми таблиць для користувачів, улюбленців, товарів).  
  * Розробка базового Backend API: реєстрація/авторизація користувачів, створення/редагування профілю улюбленця.  
* Цілі з документації:  
  * Формулювання функціональних, нефункціональних та системних вимог.  
  * Результат: Працюючі базові API-ендпоінти; Звіти по вимогах (Практичні роботи №2, №3, №4).

**Етап 3: Розробка основного функціоналу MVP та детальне проектування (14 жовтня — 10 листопада 2025 р.)**  
Розробка ключових функцій ведеться одночасно з детальним проектуванням системи, що дозволяє UML-діаграмам відображати реальну структуру коду.

* Цілі з розробки:  
  * Backend: Реалізація логіки нагадувань, підписок, API для інтернет-магазину.  
  * Frontend (Web/Mobile): Створення основних екранів мобільного додатку (профіль, календар) та сторінок інтернет-магазину (каталог, картка товару). Початок інтеграції з Backend API.  
* Цілі з документації:  
  * Створення детального плану завдань у Wrike.  
  * Розробка UML-діаграм (Use Case, Class, Sequence), що описують реалізований та запланований функціонал.  
  * Результат: Прототип мобільного додатку та веб\-сайту з ключовим функціоналом; План у Wrike та UML-діаграми (Практичні роботи №5, №6).

**Етап 4: Інтеграція, тестування та фіналізація MVP (11 листопада — 28 листопада 2025 р.)**  
Фокус зміщується на повноцінну інтеграцію всіх компонентів, виправлення помилок та підготовку до демонстрації.

* Цілі з розробки:  
  * Повна інтеграція мобільного додатку та веб\-сайту з Backend.  
  * Реалізація наскрізних сценаріїв (наприклад, "отримати нагадування \-\> перейти в магазин \-\> замовити товар").  
  * Внутрішнє тестування, виправлення багів, полірування UI/UX.  
* Результат: Готовий до демонстрації MVP (Minimum Viable Product) системи.

**Етап 5: Завершення проекту та демонстрація (29 листопада — 1 грудня 2025 р.)**

* Цілі: Підготувати фінальну звітність та представити результати роботи.  
* Результат: Фінальний звіт по виконаній роботі; Успішна демонстрація програмного продукту.

# **5\. Мета (цілі) проекту** {#5.-мета-(цілі)-проекту}

## **5.1. Цілі для власників тварин (кінцевих користувачів)** {#5.1.-цілі-для-власників-тварин-(кінцевих-користувачів)}

1. Спростити контроль за здоров'ям улюбленця. Забезпечити автоматизацію процесу догляду шляхом створення надійної системи нагадувань про вакцинації, обробки від паразитів, прийом ліків та інші важливі процедури.  
2. Підвищити зручність та заощадити час. Надати можливість замовляти ветеринарні товари (корми, ліки) безпосередньо з мобільного застосунку, впровадивши модель передплати для автоматизації регулярних покупок та усунення потреби у фізичних візитах до магазину.  
3. Централізувати всю важливу інформацію. Створити єдиний, захищений цифровий профіль тварини, де буде зберігатися вся ключова інформація: від даних про породу та вік до повної історії щеплень та медичних документів, що забезпечить легкий доступ до неї в будь-який час.

## **5.2. Цілі для бізнесу (ветеринарної клініки)** {#5.2.-цілі-для-бізнесу-(ветеринарної-клініки)}

1. Створити новий ефективний канал продажів. Розробити та запустити спеціалізований інтернет-магазин, інтегрований з мобільним застосунком, для розширення ринку збуту та отримання додаткового, стабільного доходу.  
2. Підвищити лояльність існуючих клієнтів. Надати клієнтам унікальний, корисний та зручний цифровий інструмент, що посилить їхній зв'язок з клінікою та підвищить рівень задоволеності сервісом.

## **5.3. Технічні цілі** {#5.3.-технічні-цілі}

1. Розробити надійну клієнт-серверну платформу, що складається з трьох основних компонентів: кросплатформеного мобільного застосунку "Pet Connect" (Клієнт), веб\-сайту інтернет-магазину (Веб-клієнт) та RESTful API (Сервер), який забезпечує їхню взаємодію.  
2. Реалізувати MVP (Minimum Viable Product) системи у визначені терміни, що включатиме ключовий функціонал: створення профілів, систему нагадувань, каталог товарів, процес замовлення та інтеграцію між застосунком і магазином.

# **6\. Актуальність**  {#6.-актуальність}

Проект "Pet Connect" є актуальним та своєчасним рішенням, що відповідає ключовим тенденціям ринку догляду за домашніми тваринами в Україні та світі. Його релевантність обґрунтовується стрімким зростанням ринку, змінами у ставленні до домашніх улюбленців, що все більше стають повноцінними членами родин, та зростаючою потребою у зручних цифрових інструментах для догляду за ними.

Європейці люблять тварин, і статистика це підтверджує:

* в ЄС налічується майже 7.8 млн котів і 6.7 млн собак (портал Statista);  
* за останні 10 років кількість домогосподарств із власними домашніми тваринами зросла на 26%, до 91 млн (кінець 2022 року);  
* у більш ніж половини поляків є домашній улюбленець (звіт Kantar Public 2019-го);  
* у Польщі більше домогосподарств із собаками, ніж із дітьми (цьогорічне дослідження GfK Polonia Household Panel).

**Вирішення нагальних проблем власників домашніх тварин**

Сучасний ритм життя вимагає від власників тварин значної організованості та відповідальності. "Pet Connect" пропонує вирішення низки поширених проблем:

* **Контроль за здоров'ям:** Своєчасна вакцинація та обробка від паразитів є критично важливими для здоров'я тварин. Державні установи, зокрема Держпродспоживслужба, регулярно наголошують на необхідності щорічних щеплень проти сказу. Однак, власникам буває складно відстежувати графіки щеплень та прийому препаратів. "Pet Connect" вирішує цю проблему, пропонуючи систему автоматичних нагадувань, що допомагає дотримуватися ветеринарних рекомендацій.  
* **Зручність та економія часу:** Проект інтегрує догляд за твариною з електронною комерцією. Можливість замовити корм чи ліки безпосередньо з додатку, особливо за моделлю передплати, значно спрощує життя власників, звільняючи їх від необхідності пам'ятати про поповнення запасів та здійснювати регулярні походи до магазину. Це відповідає загальному тренду на зростання онлайн-покупок в Україні.  
* **Централізоване зберігання інформації:** Додаток дозволяє зберігати всю важливу інформацію про улюбленця в одному місці: від даних про породу та вік до історії щеплень та медичних документів. Це особливо корисно під час візитів до ветеринара або у непередбачуваних ситуаціях.

Підсумовуючи, проект "Pet Connect" має високий потенціал успіху завдяки своїй відповідності актуальним ринковим трендам, здатності вирішувати реальні проблеми власників домашніх тварин та інноваційному підходу до інтеграції догляду та електронної комерції. Водночас, для досягнення поставлених цілей необхідно ретельно пропрацювати стратегію виходу на ринок та мінімізації потенційних ризиків.

  * Модуль сповіщень: Відповідає за логіку та відправку нагадувань користувачам у визначений час.

  * Профіль користувача та тварини: Можливість створення та редагування детальних профілів для кількох домашніх улюбленців.  
  * Інтерактивний календар та система нагадувань: Графік щеплень, обробок від паразитів, прийому ліків та візитів до лікаря з автоматичними push-сповіщеннями.

  Електронна медична картка: Місце для зберігання історії хвороб, результатів аналізів, призначень та рецептів.

  * Інтеграція з інтернет-магазином: Можливість перегляду рекомендованих товарів та швидкого оформлення замовлення (наприклад, замовити препарат прямо з нагадування про обробку).  
* **Веб-сайт (Інтернет-магазин):**  
  * Публічний каталог товарів: Повноцінна онлайн-вітрина з категоріями, фільтрами, пошуком та детальними описами товарів.  
  * Система електронної комерції: Включає кошик, процес оформлення замовлення (checkout), інтеграцію з платіжною системою.  
  * Модель передплати: Функціонал для налаштування регулярної автоматичної доставки товарів (кормів, ліків).  
  * Адміністративна панель: Закрита частина сайту для менеджерів, що дозволяє керувати каталогом товарів, обробляти замовлення, переглядати статистику та керувати користувачами.

## **10.3. Перспективи подальшого розвитку** {#10.3.-перспективи-подальшого-розвитку}

Створений MVP є не кінцевим продуктом, а потужним фундаментом для побудови комплексної цифрової екосистеми. Подальший розвиток проекту має величезний потенціал у наступних напрямах:  
**1\. Трансформація в єдиний медичний простір ("Helsi для тварин")**  
Найбільш амбітною перспективою є перетворення "Pet Connect" на центральну платформу, що об'єднує дані з різних ветеринарних клінік, лабораторій та державних установ.

* Єдина електронна медична картка (ЄЕМК): Власник тварини зможе надавати тимчасовий доступ до повної історії хвороби будь-якому ветеринару в будь-якій клініці-учасниці системи, що є критично важливим у невідкладних ситуаціях.  
* Інтеграція з лабораторіями: Результати аналізів автоматично надходитимуть у додаток, з можливістю перегляду динаміки показників.  
* Електронний рецепт: Впровадження стандартизованого електронного рецепту, який можна буде погасити в будь-якому партнерському інтернет-магазині чи ветеринарній аптеці.  
* Співпраця з державними органами: Інтеграція з Держпродспоживслужбою для ведення офіційного обліку щеплень, що значно спростить отримання ветеринарних документів для подорожей.

**2\. Розширення E-commerce та сервісної моделі**

* Маркетплейс послуг: Перетворення додатку на платформу для замовлення супутніх послуг: грумінг, перетримка (pet-sitting), вигул, послуги кінолога. "Pet Connect" виступатиме як агрегатор, отримуючи комісію за замовлення.  
* Кураторські бокси: Створення сервісу підписки на щомісячні "Pet Connect Box" — набори з кормом, ласощами, іграшками та засобами догляду, підібраними індивідуально на основі профілю тварини.  
* Програма лояльності та кешбек: Розробка системи накопичення бонусів за покупки, регулярні чекіни в клініці та виконання "челенджів", які можна буде витратити на товари та послуги.

**3\. Розвиток соціальних функцій та спільноти**

* Карта для прогулянок та знайомств: Інтерактивна карта з відмітками pet-friendly закладів, майданчиків для вигулу собак та можливістю знаходити інших користувачів для спільних прогулянок.  
* Мережа "Знайди мене": Система екстрених сповіщень на випадок, якщо тварина загубилася. Власник зможе в один клік розіслати сповіщення з фото та даними улюбленця всім користувачам "Pet Connect" у заданому радіусі.

Таким чином, проект "Pet Connect" має потенціал вирости з зручного асистента в центральну, незамінну платформу для всієї індустрії догляду за домашніми тваринами в Україні, що відкриває широкі можливості для подальшого розвитку та монетизації.

Команда проекту є крос-функціональною, де кожен учасник має свою основну спеціалізацію, але також залучений до суміжних процесів для забезпечення ефективної комунікації та цілісності кінцевого продукту.

**Основна роль:** Backend Lead / System Architect  
**Ключові зони відповідальності:**

* **Проектування архітектури:** Відповідає за загальну архітектуру мікросервісної системи, вибір способів їх взаємодії (REST, gRPC, повідомлення через RabbitMQ) та забезпечення узгодженості роботи всієї платформи.  
* **Розробка на .NET:** Повна реалізація мікросервісів, написаних на .NET:  
  * **BasketApi:** Управління кошиком користувача з використанням gRPC для швидкої комунікації та Redis для кешування.  
  * **OrderProcessor та PaymentProcessor:** Розробка обробників черг повідомлень для надійної асинхронної обробки замовлень та платежів.

# **12\. Залучення до проекту зовнішніх організацій (компаній)** {#12.-залучення-до-проекту-зовнішніх-організацій-(компаній)}

Для забезпечення успішного виходу на ринок, перевірки бізнес-моделі та подальшого масштабування, проект "Pet Connect" передбачає залучення зовнішніх організацій на різних етапах свого життєвого циклу. Такий підхід дозволить перетворити проект з простого програмного продукту на повноцінну цифрову екосистему.

## **12.1. Партнерство з ветеринарними клініками для пілотного запуску** {#12.1.-партнерство-з-ветеринарними-клініками-для-пілотного-запуску}

На початковому етапі ключовим є залучення однієї або кількох мережевих ветеринарних клінік для апробації платформи.

* Потенційні партнери: Провідні українські мережі, такі як "Алден-Вет", "Зоолюкс", "VetZoоПатруль".  
* Модель співпраці: Клініка-партнер отримує ексклюзивний доступ до платформи для своїх клієнтів. Інтернет-магазин наповнюється товарами, що є на складі клініки, а мобільний застосунок "Pet Connect" брендується як офіційний цифровий помічник цієї мережі.  
* Вигоди для клініки-партнера:  
  * Конкурентна перевага: Надання унікального інноваційного сервісу.  
  * Підвищення лояльності: Посилення зв'язку з клієнтами через зручний цифровий інструмент.  
  * Додатковий дохід: Отримання стабільного прибутку від онлайн-продажів та підписок.  
* Вигоди для проекту:  
  * Отримання першої бази реальних користувачів.  
  * Збір цінного зворотного зв'язку для вдосконалення продукту.  
  * Перевірка життєздатності бізнес-моделі.

## **12.2. Стратегічні партнерства для розширення екосистеми** {#12.2.-стратегічні-партнерства-для-розширення-екосистеми}

Після успішного пілотного запуску, планується розширення функціоналу та цінності продукту через інтеграцію з іншими гравцями ринку:

* Виробники та дистриб'ютори кормів і ліків: Залучення таких компаній, як Royal Canin, Purina, Hill's або великих дистриб'юторів (наприклад, Suziria Group). Це дозволить проводити спільні маркетингові акції, пропонувати користувачам ексклюзивні знижки та напряму інтегрувати каталоги товарів.  
* Страхові компанії: Інтеграція з компаніями, що пропонують страхування домашніх тварин (наприклад, UNIQA, ARX). "Pet Connect" може стати ідеальним інструментом для оформлення страхового полісу та подання заяв, оскільки вся медична історія тварини вже буде оцифрована.  
* Постачальники супутніх послуг: Партнерство з грумінг-салонами, кінологами, готелями для тварин. У майбутньому в додатку може з'явитися функціонал для пошуку та бронювання таких послуг.

# **13\. Основні позначення, абревіатури** {#13.-основні-позначення,-абревіатури}

**Загальні та бізнес-терміни**

* API (Application Programming Interface) — Інтерфейс прикладного програмування. Набір правил та інструментів, що дозволяє різним програмним компонентам взаємодіяти один з одним.  
* CRM (Customer Relationship Management) — Система управління взаємовідносинами з клієнтами. У контексті проекту — уявна система ветеринарної клініки.  
* MVP (Minimum Viable Product) — Мінімально життєздатний продукт. Версія продукту з мінімальним, але достатнім для демонстрації функціоналом, готова до запуску для перших користувачів.  
* QA (Quality Assurance) — Забезпечення якості. Процеси, спрямовані на підтримку якості програмного продукту на всіх етапах розробки.

**Технічні терміни та технології**

* AI (Artificial Intelligence) — Штучний інтелект. Технології, що імітують людський інтелект, у проекті застосовуються для розшифровки рецептів.  
* .NET — Платформа для розробки програмного забезпечення від компанії Microsoft, що використовується для реалізації частини backend-сервісів.  
* Git — Розподілена система керування версіями коду, що використовується командою для спільної розробки.  
* gRPC (gRPC Remote Procedure Call) — Високопродуктивний фреймворк для віддаленого виклику процедур, що використовується для швидкої комунікації між мікросервісами.  
* NestJS — Прогресивний фреймворк на базі Node.js для створення ефективних та масштабованих серверних додатків, що використовується для реалізації частини backend-сервісів.  
* REST (Representational State Transfer) — Архітектурний стиль взаємодії компонентів у розподіленій системі. RESTful API — API, що відповідає принципам REST.  
* UI (User Interface) — Інтерфейс користувача. Візуальна частина додатку, з якою взаємодіє користувач.  
* UML (Unified Modeling Language) — Уніфікована мова моделювання, що використовується для візуального проектування та документування програмних систем.  
* UX (User Experience) — Досвід користувача. Загальне враження користувача від взаємодії з продуктом.

**Специфічні для проекту скорочення**

* ЄЕМК — Єдина електронна медична картка. Концепція централізованого зберігання медичних даних тварини, доступних у різних клініках.
