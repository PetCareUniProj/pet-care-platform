# Pet Connect: Subscription API

This is the Subscription API microservice for the "Pet Connect" platform. It manages all aspects of user product subscriptions, including creation, cancellation, and periodic billing logic via the `SubscriptionProcessor`.

## Features

-   Create and manage user subscriptions
-   Handle recurring payments and order creation events
-   Provide endpoints for users to view their active subscriptions
-   Communicate with Ordering and Payment services

## Tech Stack

-   **Framework**: [NestJS](https://nestjs.com/)
-   **Language**: TypeScript
-   **Database**: PostgreSQL
-   **Messaging**: RabbitMQ (for scheduling and event processing)

## Prerequisites

-   [Node.js](https://nodejs.org/en/) (v18.x or higher)
-   [NPM](https://www.npmjs.com/)
-   [Docker](https://www.docker.com/) (for database and message broker)

## Getting Started

Follow these instructions to get the project up and running on your local machine for development and testing.

**1. Clone the repository:**
```bash
git clone https://github.com/PetCareUniProj/subscription-api.git
cd subscription-api
```

**2. Install dependencies:**
```bash
npm install
```

**3. Configure environment variables:**
Create a `.env` file in the root directory by copying the example file.
```bash
cp .env.example .env
```
Now, open the `.env` file and provide the necessary configuration values.

**4. Run the application:**
```bash
npm run start:dev
```
The server will start in watch mode on the port specified in your `.env` file (e.g., `http://localhost:3002`).
